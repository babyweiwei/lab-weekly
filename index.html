不用注册、不用登录。看板显示每个学生每周是否提交、有没有迟交，点开就能看 PPT。
PPT 原件留在学生的私有仓库里，点「在 GitHub 打开」用你已登录的 GitHub 账号查看。

首次使用要做 3 件事：建学生仓库模板、配好 Actions 变量与 Token、打开 Pages，详见 部署指南（约 20 分钟，不需要服务器）。
