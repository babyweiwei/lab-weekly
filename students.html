全部在 GitHub 网页里完成

0. 先说你的 GitHub 用户名

就是 github.com/ 后面那一截，不是显示的名字。

1. 一键生成我的私有仓库

点下面这个按钮，仓库名已填好、Private 已勾好，点 Create 即可

创建私有仓库

已建过就别再点（GitHub 会提示重名，直接跳到第 2 步）。

2. 上传本周的组会 PPT

先把文件放进一个叫 的文件夹，再整夹拖进去

打开直传页面

小技巧：仓库里已经有 2026-W46 这类目录时，拖入同名文件夹会把文件放对位置；不确定就先在本地建好文件夹。

3. 写本周进展（老师主要看这个）

点一下自动打开"新建文件"，文件名和模板都填好了

写本周进展

三五行就够：本周做了什么 / 卡在哪 / 下周计划。

4. 我的仓库

打开我的仓库

为什么不用登录按钮？ 创建私有仓库、上传文件，GitHub 都要求你已经用自己的账号登录了 github.com。 所以"登录"这一步就是你在浏览器里登录 GitHub，不需要本系统再要一次授权 —— 也就没有令牌可被偷。
